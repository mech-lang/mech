Grid and boundary conditions

Each cell exchanges heat with its horizontal and vertical neighbours. Boundary faces are insulated. The initial upper-left cell has temperature 80 and all other cells start at zero. The dimensionless timestep is α = κΔt/Δx². The selected α values satisfy the explicit two-dimensional stability condition α ≤ ¼. Optional heater input adds one unit to the centre cell after each diffusion step.

Actual Mech source

The source declares the discrete Laplacian and performs temperature = temperature + (laplacian ** temperature) * alpha + heater-mask * heater. The JavaScript reference visits neighbouring cells directly. Absolute comparison tolerance: 10⁻⁵. The sum of temperatures remains 80 for insulated runs; each active heater turn adds one unit.
