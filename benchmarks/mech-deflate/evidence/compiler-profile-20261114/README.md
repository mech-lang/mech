The latest qualified complete source-to-Object process takes **18.467–18.483 seconds**, using the opt-in `compiler` build profile. Nested existing base predictions reduce parsing 13.87%, complete-process time 2.20% and retired instructions 2.29% in eight matched compiles. Both balanced blocks improve; every generated byte matches. Preparation is an adverse 0.41% higher, cleanup including compaction 0.68% higher and memory slightly higher with overlapping ranges. All phases/counters remain. The 526 document-module units, 1,667 complete parse comparisons and fourteen fixture pairs pass. Seven separate CPU windows point to SSA variable lookup/storage, graph cleanup and frontend dimensions as remaining work. Grammar and logical accounting are unchanged. The separate 403.6-second compiler rebuild is excluded from Mech compilation; both subjects use identical 60 runtime flags. The ten-second goal remains open.

The [local-span SSA trials](../../../../docs/design/native-ssa-span-trials.md) tested two private storage layouts against the retained compiler in separate eight-observation cohorts. Source CFG construction regresses 5.53% and 5.07%; compiler phases regress 0.61% and 0.94%; instructions regress 0.55% and 0.48%. Every output byte matches, but both compiler-time blocks are slower for each variant. Both are rejected, production source is restored, and all measurements remain in the eighteenth packet. Source inspection finds common entry definitions that weaken the locality hypothesis; deferring unnecessary zero seeds is unimplemented.

Rejected evidence stays here: SSA forwarding repeatedly slows the compressor, and two backend-reuse approaches fail to establish a useful overall compiler saving. All adverse measurements and transient corrections remain in their packets.

To verify and replay a packet from a checkout, use a fresh extraction directory. This example needs Python 3.11+ and repository files; it does not compile or execute the benchmark:

```sh
python3 benchmarks/mech-deflate/experiment.py verify benchmarks/mech-deflate/evidence/compiler-profile-20261114/mech-nested-parser-20261114.tar.gz --receipt benchmarks/mech-deflate/native-profile/nested-parser-compile-apple-m3-20261114.archive.json --extract /tmp/mech-nested-parser-retrieved
python3 /tmp/mech-nested-parser-retrieved/replay.py > /tmp/mech-nested-parser-replayed.json
cmp /tmp/mech-nested-parser-replayed.json benchmarks/mech-deflate/native-profile/nested-parser-compile-apple-m3-20261114.json
```
