To verify and replay a packet from a checkout, use a fresh extraction directory. This example needs Python 3.11+ and repository files; it does not compile or execute the benchmark:

```sh
python3 benchmarks/mech-deflate/experiment.py verify benchmarks/mech-deflate/evidence/compiler-profile-20261114/mech-scope-graph-20261114.tar.gz --receipt benchmarks/mech-deflate/native-profile/scope-graph-compile-apple-m3-20261114.archive.json --extract /tmp/mech-scope-graph-retrieved
python3 /tmp/mech-scope-graph-retrieved/replay.py > /tmp/mech-scope-graph-replayed.json
cmp /tmp/mech-scope-graph-replayed.json benchmarks/mech-deflate/native-profile/scope-graph-compile-apple-m3-20261114.json
```
