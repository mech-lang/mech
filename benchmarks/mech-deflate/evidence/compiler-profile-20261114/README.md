To verify and replay a packet from a checkout, use a fresh extraction directory. This example needs Python 3.11+ and repository files; it does not compile or execute the benchmark:

```sh
python3 benchmarks/mech-deflate/experiment.py verify benchmarks/mech-deflate/evidence/compiler-profile-20261114/mech-exit-definitions-20261114.tar.gz --receipt benchmarks/mech-deflate/native-profile/exit-definitions-compile-apple-m3-20261114.archive.json --extract /tmp/mech-exit-definitions-retrieved
python3 /tmp/mech-exit-definitions-retrieved/replay.py > /tmp/mech-exit-definitions-replayed.json
cmp /tmp/mech-exit-definitions-replayed.json benchmarks/mech-deflate/native-profile/exit-definitions-compile-apple-m3-20261114.json
```
