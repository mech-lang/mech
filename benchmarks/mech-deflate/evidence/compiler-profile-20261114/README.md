To verify and replay a packet from a checkout, use a fresh extraction directory. This example needs only Python and repository files; it does not compile or execute the benchmark:

```sh
python3 benchmarks/mech-deflate/experiment.py verify benchmarks/mech-deflate/evidence/compiler-profile-20261114/mech-visit-predecessors-20261114.tar.gz --receipt benchmarks/mech-deflate/native-profile/visit-predecessors-compile-apple-m3-20261114.archive.json --extract /tmp/mech-visit-predecessors-retrieved
python3 /tmp/mech-visit-predecessors-retrieved/replay.py > /tmp/mech-visit-predecessors-replayed.json
cmp /tmp/mech-visit-predecessors-replayed.json benchmarks/mech-deflate/native-profile/visit-predecessors-compile-apple-m3-20261114.json
```
