## When to implement a family summary

Consider the largest family by measured exclusive time plus any identifiable nested replay work it would also remove. Subtract the cost of recording and replaying the recipe. Require a plausible complete-build gain of around 0.1 seconds or a substantial structural or memory reduction for extended work. If the winning speculative run does different work from the final execution frequently, find a structural invariant for the subset before assigning the apparent coverage any value. Exact aggregate counters cannot establish an equivalent event and cache schedule for arbitrary inputs. Finish diagnosis within 60–90 minutes. Park the experiment after two flat or adverse iterations unless new evidence changes the payoff.

Keep the grammar declaration and actual selection untouched. A scoped summary, if admitted, belongs to the current choice, bounded to its known source span and shape. On successful application it must recreate ordered events, including resulting tombstones and relative token ranges and flags. Node IDs are allocated on marker completion, and cached subtree construction assigns token IDs separately. Preserve ID holes from nested discarded work. Each fresh ID is relative to the new allocator state and all dependency/publication points must be represented. A speculative cached tree can supply recipe data only if replay emits fresh IDs in the existing allocation order.

Prove that source extent, consume and context frontiers, grammar state, parser rule/marker shape, consuming-recovery policy, relevant memo inputs and outgoing effects are compatible. Rewinds do not reset allocator cursors, fuel, lexical caches, raw grapheme state, deferred tree-cache work or global peaks. The later trials still evolve those inputs before final replay. Preserving a trial event slice alone cannot preserve replay. A variant has to prove when those mutable states can differ harmlessly or decline application before any replay mutation. Record cache requests and stale outcomes if the family requires them. Preserve the final raw scanner state when a later grammar step could consume it. Use checked allocator deltas and refuse ambiguous ID saturation.

Use an all-or-fallback admission rule. Prove all logical work fits the current poll grant, all parser charges fit remaining fuel, and the original transient event count plus open-marker finish reservations and emergency envelope fit event limits. Preserve relative rule and nesting peaks and every exposed counter. Leave partial input, segmented storage, unsupported fences, recovery, halted/committed selections and insufficient grants on the same canonical continuation before changing parser state. Design the admission rule to cover any finite poll partition in tests. In particular, a pause during selection cannot be treated as a completed branch, and a poll ending during cached token-byte work can fall inside a UTF-8 scalar.
