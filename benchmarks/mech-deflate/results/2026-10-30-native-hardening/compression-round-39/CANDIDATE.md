# Reuse native parent pieces around ordinary scalar children

The unchanged optimal-path fixture fails the new selection check against frozen
round 38: no native parent piece surrounds OptimalPathMatches and its nested
OptimalPathLengths. Real full-program parent iterations 136/170/300 currently
account for 2424 ordinary admissions. That source requirement, not a synthetic
speed claim, motivates this bounded selection change.

Composition still requires one immediate Tail child and a flat private-frame
parent. The existing qualified numeric array-frame child route is unchanged,
including append refusal. A second route permits an ordinary child only when
the existing connected scalar-aggregate proof covers its flat return record,
and every loop in its descendant tree has a private scalar carrier and no
buffer-frame carrier. Thus no descendant can open another selected private-frame
parent edge: the existing single eight-byte pending edge remains sufficient.
Multiple children, mixed/unknown descendant state and collection loops decline.

Every native piece still derives its own acyclic, single-entry graph and exact
scalar/frame/array sources, exits, prices and ordered retirement. It closes
before any child entry. The ordinary initializer, all child/grandchild visits,
assertions, exit and successor remain authoritative. No owner, view or fuel is
carried through the child. Current post-call state is acquired afresh.

Compilation and build-owned image loading call the same derivation with their
existing scalar/frame proofs. The scalar-return predicate is shared with numeric
leaf result qualification rather than reimplemented. `scalar_child` is
descriptive metadata, not a caller-supplied execution capability. No protocol,
ABI, word bank, owner, executor, source algorithm, work price or limit changes.

Six focused maintained tests pass: the four prior cases plus a changing-Boolean
child result with success→assertion-before-division rejection→arithmetic rejection
→unselected invalid child→retry, and six finite dimensions at exact/one-short
boundaries in original/decoded forms. Actual callbacks count every reached child
initialization/exit and require selected native pieces. Input aliases, previous
publication, retained bytes/nodes and final zero cleanup are checked. Existing
Huffman work and its finite thresholds stay unchanged.

Two early versions of the new test fixture had incompatible row/general-matrix
schemas around an append/recursive argument; both were rejected before native
execution and preserved in the failure receipts. The final minimal Boolean
witness keeps its input array immutable, observes its length and returns a scalar
through the same child boundary. A standalone source-check adapter initially
passed `&String` instead of `&str`; corrected diagnostic setup is retained. None
of those setup fixes modifies the benchmark or expands the compiler task.

No elapsed, instruction or allocation improvement is claimed until the real
component, full computation, controls and paired measurements finish.
