# Remove temporary numeric matrix validation allocations

The first allocation-targeted optimization is retained. The complete eight-byte level-12 compressor makes **13,484 → 10,119 allocation requests (−24.9555%)**, takes **13.841374× → 13.556068×** one shared fresh reference time (−2.06125%), and executes **45,055,355.5 → 43,759,276.5 instructions (−2.87664%)**. Peak tracked memory is unchanged. This is a small metadata optimization with a measured time benefit, not a claim of parity or larger-input speed.

Core's typed numeric matrix constructor used to copy its shape parameters for validation, copy them again while closing the schema, allocate a temporary scalar schema body, build a dimension vector and shrink it. The census reaches this constructor 673 times: five temporary requests plus three retained immutable owners each. It now invokes Core's existing complete shape-parameter/bound/body-extent validator through a crate-private borrowed helper, reads the original immutable schema body and resolves its dimensions directly. It still checks unknown schema, parameter count and bounds, dimension overflow, exact plain scalar kind, matrix cardinality and Index nonzero rules in the original order. Shape instances carry values rather than schema identity, so foreign shapes are still revalidated against the target schema.

This removes temporary construction, not validation. No cached permissive witness or new public authority is added. Frozen storage, retained owners, admission/claim rules, work prices, error classes, schemas, codec, image format, ABI and source algorithms are unchanged. The raw Object, build-owned image and metadata are byte-identical before/after: IR/work/ABI/bytecode **132/95/37/14**, text **13,046,668 bytes**, stack **108,368 bytes**. The optimization is in the linked Core runtime.
