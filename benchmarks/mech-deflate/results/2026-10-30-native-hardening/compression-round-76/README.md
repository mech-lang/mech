# R76 cold debit error transport

A one-file runtime experiment keeps successful debits separate from full-error forwarding after releasing the existing mutable account borrow. It preserves the public error types, ledger, checks, finite/error-prefix semantics and invocation layout.

Acceptance requires complete matched eight-byte compression, separate hardware/heap/profile cohorts, actual linked host-code evidence and full maintained local qualification. See REPORT.md, scorecard.json and validation.json for the actual decision. Standalone reconstruct.py hash-verifies and replays committed raw evidence without a compiler or compressor. Synthetic controls retain their limits; they are not timing evidence.
