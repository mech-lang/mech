## Ownership, execution and publication

This extends the existing numeric recurrence and `PrivateUnsignedMatrix`, rather than creating another executor or payload owner. Engine recognizes only the maintained exact unsigned append factory and matching element/output schemas. Existing private-use closure, root association, fresh-version analysis, checked scalar emission, suspension, funding and result synchronization remain authoritative. An old functional array's length is no longer assumed current after append; unsupported geometry or stale versions keep the ordinary route.

Core optionally prepares metadata for an unconstrained dynamic unsigned row before a native loan. The preparation has no source Value, data identity, payload pin or mutation authority. Admission/allocation denial declines the optimization. The first reached change executes the original selected append/replacement factory, preserving copying, aliases, checks and error order, before consuming its exclusive result into the same private owner.

Initialized length and actual capacity are separate. Before each traversal, a conservative count of all append sites must fit in spare capacity. A miss leaves at the existing header boundary before source operations, commits the preceding initialized prefix and resumes ordinary execution; the original append can then grow storage. A funded native append performs a typed store before advancing length. There is no growth, whole-buffer concatenation, zero-filled path matrix or per-element runtime call in that body.

The reserved pointer comes directly from the actual Vec allocation, without forming a cell slice while its synchronous loan is live. Core's narrowly documented unsafe prefix commit checks mode, non-shrinkage and actual capacity before `set_len`; the sealed emitter establishes typed initialization. Publication updates only the prepared unbounded row parameter, restores the common data/value/registration shape and exposes the immutable owner. Scratch metadata is admitted before the loan, so finish allocates/admit nothing. Failure drops private storage and its original charge without changing previously published outputs. See [design](DESIGN.md) and the [Vec allocation-pointer contract](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.as_mut_ptr).
