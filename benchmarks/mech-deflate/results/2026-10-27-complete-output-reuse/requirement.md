# Output reuse through the complete compressor

Patch base: `c1d20645d7b58f6b21847f51bfbf37225b6e6679` (#970). Production compiler: `115188e17032e26341dd7983e0634589a9a490ab` (#967). The twenty-five compressor component files remain unchanged from `566dfd1df2eb81eb95e2804d6b50a6334bdaca42` (#968).

The reference caller clears and reuses its output reservation between complete `compress_into` calls. The earlier sequence-only allocation test did not establish that this also works through the assembled compressor. Add an explicit manual regression that allocates the output once, then makes zero, one or two complete calls inside a single compiled Mech computation. Each reached call uses `sequence/clear` on the preceding output. Compression, including the real tree, cache, path reservation and Huffman workspaces, remains entirely in the original Mech components.

Use the existing eight-literal input and its unchanged exact reference stream. The comparison varies only the caller's output reservation: 16 bytes (enough for this stream) versus the real 6633832-byte reservation. It does not shrink the tree, cache, path buffer, tables, depth, nice length or pass count. For each repetition count, first warm the descriptor at the smaller capacity, then measure both capacities. All configurable compilation, analysis, execution, library and managed budgets are at maximum via `NativeProgramLimitMode::NoLimits`.

The maintained shared helper passes eighteen native evaluations: six descriptor warmups and twelve measured evaluations, in original and decoded forms. These evaluations contain eighteen complete compressor calls in total. Every nonzero run matches the reference bytes and independently inflates. Every run preserves input and alias values, retains the requested capacity, and releases all managed bytes and retained snapshot nodes afterward.

All six allocation comparisons have identical request counts at the two capacities. The requested-byte difference is exactly `6633832 - 16 = 6633816` for zero, one and two complete calls. Only the initial reservation scales with capacity; repeating clear/compress does not add another capacity-sized allocation. Source length is 161137 bytes, SHA256 `a1b28e6ff28a3a677a0e409b8917bfcf5c4d5dd237acd31ad56df370f9baad2b`. The source was checked equal to the preceding prototype; the maintained helper freshly compiles source and creates original/decoded artifacts rather than trusting a cached artifact.

The focused release run executes this exact shared test module and completes in 145.646616220 seconds. The maintained Rust test binary also compiles with `canonical-native-program`. This is one explicit manual Rust test, not eighteen libtest tests. Its command is `cargo test --release --locked --offline -j1 -p mech-gpu --no-default-features --features canonical-native-program --test canonical_artifact_program compress_qualification::complete_level12_repetitions_retain_the_output_reservation -- --ignored --exact --nocapture --test-threads=1`. It is ignored in ordinary runs; the unoptimized libtest execution is not repeated. Exact commands, hashes and completed receipts are retained.

These elapsed times are allocation/correctness investigations using the System allocator, allocation instrumentation and concurrent runs. They do not establish matched final benchmark timing. A separate borrowed-host caller investigation preserves capacity but allocates new backing at clear/append boundaries because its immutable input must remain valid. That expected borrowed-entry behavior must not be presented as physical output reuse. The compiled Mech caller tested here does establish the required reservation behavior without changing compiler/runtime ownership rules.

No production compiler or compressor behavior changes and no optional optimization. The sixteen-kilobyte block-transition, thirty-three-kilobyte window-transition and full-file investigations remain separate, live and incomplete. This allocation result does not prove those pending cases or complete the full benchmark. CI remains cancelled at the user's request and #970 remains draft.
