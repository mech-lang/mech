# Complete-compressor round 01: eight literal bytes

Compiler head: `c24984b402a1228cccf934a478965143b539f611`.
Roc is **1×**. On Apple M1/macOS ARM64, level-12 `abcdefgh` compression is:

| Engine | Median seconds | Time divided by Roc |
| --- | ---: | ---: |
| Pinned Roc | 0.000290 | 1× |
| Mech | 1.669296125 | 5756.19× |

Three retained Mech observations are 1.670429959, 1.669296125 and 1.667431542
seconds. One initial warmup is excluded; it already exceeds the reference's
200 ms warmup duration. The existing reference executable retains all 20000
observations, with its original 200 ms warmup and microsecond-resolution clock.
This is a small diagnostic baseline, not a paired statistical campaign or a
full-corpus measurement. No large input was run. The 1× goal remains unachieved.

Both executables use the identical pinned mimalloc 2.1.7 object, without Rust
allocation instrumentation. The timer covers the complete compression call,
including scratch initialization/destruction and Mech's normal entry, resource,
validation and publication work. Output reserve, clear/prefix preparation,
argument rebinding, JIT, result checks and output disposal are outside. The
same high-level caller reserve is 13 bytes. The 25 Mech compressor components
match the maintained assembly byte for byte; only the existing external-buffer
caller entry is used. Real tree/cache/path/Huffman state and all six deliberate
initialization sites remain. The guest artifact and source hashes are recorded.
Mech currently changes backing during compression despite retaining capacity;
this observed immutable-handoff cost is included, not hidden by a fresh private
benchmark buffer.

Every compression exactly matches the ten pinned raw bytes. Independent
inflation, input immutability, capacity checks and zero final managed bytes/nodes
pass. Runtime policy is the existing diagnostic NoLimits mode, unchanged;
finite-policy public qualification is a separate requirement. Source compilation
and JIT are outside the compression timer. Builds and old compression jobs were
stopped before the round. Normal user/system activity was not isolated.

A separate final observation is sampled **after** all primary observations and
excluded from the median. Its time is 2.281956459 seconds. The profile again
reaches `indexed_assign_snapshot`, `projected_snapshot_matrix_output`,
`charge_compute_work`, planning checks and current-turn budget checks. The frame
microbenchmark's reduction therefore cannot be presented as the same whole-
compressor speedup. Historical complete timings used different instrumentation
and allocator conditions; they do not isolate the effect of this patch. This
round establishes the reproducible whole-compressor starting point for the
next compiler change, which must be timed on the same eight-byte witness and
reported against Roc's 1× baseline before scaling input.

`results.json`, raw observations and compressed samples preserve the round.
`current-final-build.json` pins the actual optimized libraries; the compiler
production behavior includes the typed-frame change and public policy API.
The subsequent recipe-test strengthening changes only cfg(test) code. A failed
attempt to relink older compiler libraries found overwritten unversioned
machine-crate dependencies; no older compiler timing is claimed. The first
probe build also required an explicit boxed-slice type. Those failed attempts
remain alongside the passing build. The retained source snapshot and allocator
adapter are provenance files, not product compiler/runtime modules.
