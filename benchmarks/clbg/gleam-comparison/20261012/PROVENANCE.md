# Source provenance and general runtime services

These are locally authored Gleam adaptations of the canonical algorithms already retained in this worktree's Nim `nim-comparison/20261012/sources` and faithfully corrected Erlang `erlang-comparison/20261010/sources` cohorts. Original sources, upstream pages, contributor attribution and license remain in the Erlang `upstream/` directory and are preserved. No timing or LOC is copied from those cohorts. The final proposal binds the exact source/provenance files used.

The Erlang originals retain contributors including Isaac Gouy (trees), Hynek Vychodil, Alexander Fyodorov, Sergei Matusevich and Thanassis Avgerinos (regex), plus the contributor names in each original workload. This candidate follows the existing faithful corrections: real dynamic leaves, complete PBM tails, strict unscaled CDF sampling, all seven K maps and exact-token third-record handling, case-sensitive ordered regex replacements, and full prescribed work. Full contributor inventory will be sealed from the retained originals before bootstrap; all new Gleam and generic glue are attributed as local adaptations.

Official stdlib: https://hex.pm/packages/gleam_stdlib/1.0.5 and https://github.com/gleam-lang/stdlib/tree/v1.0.5 . Runtime: https://www.erlang.org/downloads and https://www.erlang.org/doc/ . BEAM Int is unbounded: https://tour.gleam.run/basics/ints/ ; Gleam Dict is an ordinary Erlang map: https://gleam.run/documentation/externals/ . Native actual compiler/runtime receipts are pending.

Regex delegates only generic pattern compilation and one indexed search to OTP `re` (its actual bundled engine/version is verified later). Gleam owns all nine count loops, header/newline filtering, five sequential replacements, output spans, ordering and results. No global `re:replace` or host benchmark function is used. Integer arithmetic uses BEAM's ordinary arbitrary precision operators; no Pi host kernel exists. IO/format/vector/task/reference FFI services are generic and all authored declarations/implementations count per compiled application bundle. No custom NIF, native domain executor or second engine variant is proposed.
