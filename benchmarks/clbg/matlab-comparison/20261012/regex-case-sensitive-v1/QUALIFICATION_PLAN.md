# Additive MATLAB case-sensitive regex proposal

The preserved 20261010 applications count with `regexpi`. MathWorks R2026b documents it as case-insensitive and documents `regexp` as case-sensitive with the same call syntax. Mech's measured application, the independent byte oracle and the inspected upstream C/Rust programs use case-sensitive patterns. The new source copies change only the count operation to `regexp`; nine pattern searches and five sequential `regexprep` substitutions remain visible in MATLAB.
