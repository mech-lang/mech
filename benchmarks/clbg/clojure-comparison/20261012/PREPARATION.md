# Guarded first preparation

Candidate controller: revisions/private-v1/guarded_prepare.py. Candidate tests and fixture runner are source-only and unexecuted.

The first --seal holds the common mutex while running the exact mock-only ownership inventory from the retained generic service and the exact local command/bundle fixture inventory, with inherited mutex descriptors. It fetches only official publisher checksum metadata for the selected full JDK and three Maven jars, and pins the complete candidate, generic service, reference sources and legacy Temurin proof. It downloads no JDK/JAR executable payload and starts no subject Java process. The resulting exclusive proposal is sealed-awaiting-root-review.

After root reviews that exact digest, --prepare requires a fresh explicit revision and a nonblocking local owner lock before awaiting the common mutex. It rechecks every sealed pin, copies an exclusive source snapshot, downloads the exact JDK and vendor jars, verifies retained publisher checksums, and retains SHA256 of the actual bytes before loading them. It extracts only safe members into a fresh local JDK tree and pins that entire runtime tree. Actual java/javac/javap versions, JVM properties/collector, Mach-O ARM64 headers and linked native images are retained via owned commands with the common descriptor.

Each of twenty applications gets a fresh package containing exactly its main and generic helper, copied byte-for-byte from the snapshot. Clojure compile runs with an explicit compile-path and direct-linking true, and retains its command, input inventory and every emitted class. The runtime row binds actual main/helper sources, all generated classes, the three vendor jars, launcher/libjvm/modules/native images, exact runtime classpath and controlled Java environment. No authored source root enters the measured classpath.

Bounded cases include all existing numeric edge sizes and complete independent DNA fixtures, plus preheader sequence handling for revcomp. Numeric expected outputs use the retained independent reference, with its explicit nbody float validator. K uses the exact-token DNA oracle; >THREEBAD and vertical/form-feed controls cannot select a record. All actual stdin, expected/actual stdout, raw sampler and supervisor evidence bytes become terminal pins. Original raw failure artifacts are retained separately from parent wrapper diagnostics. Failure stops this preparation revision with no implicit retry.

Successful first preparation is still bounded-only and unscored: actual work observers and javap/source review are required before a separate full-study seal. Tree proof must inspect actual allocated nodes including distinct leaves, every churn root, and the same retained graph after churn. K proof must inspect all seven complete growing maps and overlapping windows on arbitrary input, exact owner/join lifetime and a genuine growth fixture. Pi proof records both real extraction operands/divisors/quotients for accepted and rejected attempts, plus zero. Observer source is additive, separately compiled and cannot replace measured source.
