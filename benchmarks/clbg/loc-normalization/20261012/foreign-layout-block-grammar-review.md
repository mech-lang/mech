# Source-specific review of layout and Smalltalk block families

This additive review covers **F#, Roc, Elm, and Smalltalk** from the frozen [foreign current-policy catalog](foreign-current-policy-review.json): 65 registrations across 60 distinct family/source-SHA pins (F# 30/25, Roc 11/11, Elm 11/11, Smalltalk 13/13). Exactly two representative source files per family were inspected through bounded excerpts. It does not certify the complete source pool or admit numerical corrections.

The same global rule applies here: independent declarations/body actions remain visible; named function/control headers require ownership; explicit executable callbacks retain header/body/written-close events even when their body is a single expression. The parent's explicit Ruby example `map { |x| expr }` therefore cannot be collapsed merely because it is concise. Only actual expression-operator/lambda forms qualify for the reviewed expression treatment, and nested independent bindings/actions do not disappear inside them. Layout dedents are not written closing tokens, and data delimiters are not executable block closes.

No imports, parsing, lexing, normalization, source/report hashing, tests, builds, Git operations, or source sweep ran. This review only records expected metadata pins and static source evidence. It changed no normalizer/helper, original source/report, count, timing, or frozen job.

## Uniform grammar and admission gates

The shared event model must cover independent bindings, named method/function definitions, actual control/function bodies, and explicit callback boundaries. Language-specific ownership is required for layout; let/in sections; pattern/type alternatives; true lambda syntax; executable computation expressions nested inside data construction; type fields versus record values; tuples/formals/destructuring; and Smalltalk message, temporary, class, method, and file-in roles.

Focused review fixtures should include F# mutable fields versus formal record patterns, literal separators versus imperative semicolons, async blocks inside comprehensions, and nested lambda locals; Roc when arms/pipe formals/record updates/division versus comments; Elm compact let/in, nested named functions and case patterns, and record-update pipes; Smalltalk no-argument/argument callbacks with one expression, nested/packed closes, grouped temporaries and reflective class fields, cascades, periods in decimal literals, comments/strings/characters, and method/category chunk delimiters. A pure one-expression **explicit block callback remains expanded** under the same rule already required for Ruby.

Before a display overlay is admitted, a locked pass must verify each exact source and producer/report/tool pin, apply the reviewed common policy to all 60 distinct sources, and reconcile execution-mode aliases only when source identity matches. Preserve historical producer LOC/ratios and every timing sample. Missing grammar evidence stays pending review; no old physical count, empty expansion array, nonzero expansion, label, or policy comment substitutes for canonical admission.
