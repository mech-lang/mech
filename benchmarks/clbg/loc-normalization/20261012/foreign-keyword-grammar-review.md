# Source-specific review of the foreign keyword families

This is an additive static review of **Ada, Pascal, and Fortran** from the frozen [foreign source catalog](foreign-current-policy-review.json): 48 displayed registrations and 48 distinct family/source-SHA pins (Ada 17, Pascal 15, Fortran 16). Exactly two representative source files per family were inspected in bounded excerpts. This is not a whole-pool grammar certificate.

The common boundary rule remains header 1 / standalone executable opener 0 / independent body units / written executable close 1. Keyword ownership must distinguish executable blocks from declaration/type/interface scopes, formal lists, aggregates, and continuation lines. No new counts or numerical overlays are admitted here. Original sources, producer counts, reports, samples, normalizer code, and frozen jobs were not changed. No imports, parsing, normalization, hashing, tests, builds, Git operations, or source sweep ran.

## Common reuse and pending gates

These representatives justify a common **owner/event model**, not common punctuation heuristics. Named executable routines, control headers, independent local/field declarations, standalone `begin` openers, and written executable ends can share the approved event semantics after language-specific recognition. Type/package/module/interface scopes and compiler directives must use explicit reviewed policy, rather than fall through as executable blocks or discarded comments.

Focused review fixtures should cover: multiline Ada formals/defaults versus grouped locals; Ada forward/renamed declarations and named aggregates/attributes; Pascal routine headers versus external declarations, directive components, compact record fields, main bodies without a written program heading, `repeat/until`, and unbraced `else` bodies; Fortran attribute/entity commas, functions with result clauses, `endif`/compound named ends, pointer association, free-form continuations, and OpenMP retention/boundaries. Semicolons terminating one statement or declaration must not automatically create an extra unit.

The next locked pass must verify every exact source/producer/report/tool pin and reconcile the complete 48-source subset under the same global policy. Preserve historical producer counts/ratios and timing samples, emit only separate reviewed display overlays, and leave unsupported/ambiguous syntax pending explicit review. Neither an old empty expansion array nor a nonzero old expansion is a canonical certificate.
