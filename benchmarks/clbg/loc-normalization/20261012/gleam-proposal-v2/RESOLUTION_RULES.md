The later rule must consume exact qualified compiled-input inventory, source,
helper and vendor pins under the common mutex before imports or parsing. It
preserves every expression node/operator/order/short-circuit, binding, callable,
arm and written close in the original owner AST. A certificate binds caller
path/hash and precise diagnostic span/AST, enclosing function and visible lexical
bindings, each resolved declaration path/hash/span/signature, external target or
complete named function body, and exact vendor source/version receipt. No
language name, path, filename or bare function-name exemption supplies proof.

At each call, resolve the module alias and local name through actual imports,
function formals, preceding sequential let/assert patterns, callback formals and
case patterns. A nearer value binding wins over a module/local-function name.
Reject shadowing, ambiguous imports, an unknown callee, changed caller/helper/
vendor bytes, changed FFI target/signature and unresolved result/argument shape.
Do not infer absence of effects merely from scalar return type.

There are two bounded composition rules:

1. One-expression scalar grouping. The brace has exactly one expression and no
let/assert/use, inline fn/case, additional statement, mutation or callable owner.
Resolve io.sqrt to counted clbg_io declaration Float -> Float and exact Erlang
math:sqrt target; retain its external annotation/signature as independent source
units. Resolve io.byte to counted BitArray/Int -> Int declaration and binary:at,
with proved operand types. The optimized K code(Int)->Int call must resolve to
the exact separately counted local case: four constant alternatives and its
explicit invalid-input panic arm. This is bounded value-expression composition,
not a blanket runtime purity assertion; panic/error and byte bounds behavior
are unchanged. Numeric/Boolean operators and literal/formal/visible scalar
values compose only with matching types. Preserve || and && evaluation order.

2. Collection value prefix before first directly nested fn. Resolve exact
standard library dict.to_list and list.sort plus the named compare function.
Compare's complete nested case/constant order result body is independently
counted, with no I/O/write/unresolved call/extra callable body. This does not use
the scalar-result rule. Only that proved prefix can share the containing written
call owner with its first directly nested fn header under the approved policy.
The callback body/close, additional callback headers/bodies/closes and every
independent preceding let/write/call statement remain charged. Changed comparator
body/target, local/formal shadowing, an extra binding/body before control, an
unknown/mutating comparator and an extra callback cannot gain this composition.

Selected source-bound positives are nbody compact/optimized squared*sqrt(squared),
K both forms' width/byte short-circuit grouping, optimized K's key/code(byte)
arithmetic grouping, and both K frequency sort(dict.to_list,compare) prefixes.
The final prepared main paths must come from the actual compiler inventory,

A positive must assert exact retained owner spans and unchanged helper/comparator
