# Clojure canonical source-unit proposal v2

This is a separate, unexecuted grammar candidate. It changes no normalizer, benchmark, compiler packet, measurement, or published row. The language is Clojure; neither Lisp aliases nor generated JVM classes establish its source LOC.

The reader follows the selected forms in the official [reader reference](https://clojure.org/reference/reader) and tagged [1.12.6 LispReader](https://github.com/clojure/clojure/blob/clojure-1.12.6/src/jvm/clojure/lang/LispReader.java). It preserves offsets and list/vector/map/set identity, comments, commas, strings, regexes, character delimiters, quoted data, attached metadata, recursive next-active-form discard, and anonymous function syntax. It does not execute custom readers, reader evaluation, or namespace resolution. Unknown dispatch, syntax quote/unquote, reader conditionals, generated destructuring, and malformed owners require review.

Written ownership is derived from the official [special forms](https://clojure.org/reference/special_forms) and tagged [core definitions](https://github.com/clojure/clojure/blob/clojure-1.12.6/src/clj/clojure/core.clj). The proposal recognizes the body positions of the selected `defn`, `fn`, `let`, `loop`, `if-let`, `when`, `doseq`, `dotimes`, `for`, `cond`, `case`, and `reify` forms, plus `try`/`catch`/`finally`. No macro expansion contributes generated declarations or synthetic closes.

An explicit definition/function/control owns one written header, independent written body expressions or initialized binding producers, and a written semantic closing parenthesis. Parameter vectors, destructured parameter names, call delimiters, and iterator/condition vectors are structural. A vector destructuring binding receives one initialized producer unit; generated locals do not add units. Each `let`/`loop` binding pair remains independent even when packed. Ordinary scalar call nesting and literal/data wrapping remain composed; literal/data wrapping retains its physical source rows. Conditions with further unproved executable owners are diagnosed.

Explicit `fn` bodies and `reify` methods remain executable when embedded inside another call or vector. Live vectors/maps evaluate their contents and cannot hide a nested `do` or callback. Quoted forms are data. Expression-only `#(+ %1 (* %2 2))` is one recursively proved scalar composition; that proof is restricted to a named bounded scalar operator set. A stateful anonymous callback such as `#(.get %)` owns its written callback header, body expression, and close. `#(do ...)` exposes the actual written `do` owner without counting an implicit generated `fn` or parameter vector. This rule is based on actual source forms and never on a benchmark path or expected count.

The containing call or initialized-binding prefix merges with only its first directly nested written function/control header, following the qualified shared callback policy. The `mapv` callback with two body expressions therefore receives four units. Additional callbacks retain their headers, every body and close remain written, and independent earlier effects/bindings retain units. Unproved executable arguments preceding the first callback forbid merging and require explicit source ownership review. Fixtures cover an earlier `do` effect, two independent bindings, a second callback, and a stateful preceding argument.

Namespace declarations receive a semantic namespace header and close, one unit for each authored required library spec and imported Java class, and one for each authored namespace directive such as `:gen-class` or `:refer-clojure`. Package/vector separators are structural. No generated `-main` Java methods are counted. Namespace declaration policy is an explicit review item in this candidate rather than inferred from arbitrary argument vectors.

Only literal metadata/attribute payloads, selected vector package/class imports, bare `:gen-class`, and `:refer-clojure :exclude [names]` are structural. Executable attributes/type-hint metadata, nonempty generated-class options, grouped import list forms and unproved namespace options remain diagnostic. Malformed `case` produces a signature diagnostic instead of indexing a missing selector.

Ordinary callable positions must be selected Clojure core functions, exact reviewed helper aliases, Java interop, authored function definitions, or lexically bound callable parameters. Unproved macro/function body positions remain diagnostic. This bounded inventory must be extended and requalified before unrelated language forms are admitted. `defmacro`, `deftype`, `defrecord`, threading macros, lazy generated scopes, map destructuring, pre/post maps, iterator modifiers, and the `comment` macro are currently gated.

The language-neutral `foreign_core.count_owned` supplies unchanged offset/event accounting from qualified LOC18. The new Clojure reader supplies all actual event ownership; no braced-language classifier or Pygments language alias is involved. Qualification must freeze the reader, selected fixtures, this document, inventory controller, and exact LOC18/Pygments dependency snapshot. Every fixture must be discovered and started once with zero failure/error/skip/expected-failure/unexpected-success outcomes. A parser pass remains a proposal until source-specific semantic review.

The original input inventory is exactly twenty authored mains under `clojure-comparison/20261012/sources/clbg/<benchmark>/<form>.clj` and the entire `support/clbg/support.clj`. Each scored profile is counted as its main plus the same authored support file. Helper functions for argument parsing, byte input, formatting/flush, capped generic jobs, callable submission, and join/cleanup all count. Vendor Clojure/spec/JDK classes and emitted `.class` files are build/runtime evidence rather than authored source. The actual compiler-bound main/support inventory must be independently qualified before a publication overlay.

The source-only controller will replay all 21 unique original files only after its locked exact fixture run passes. Any source diagnostic prevents qualified semantic admission and is retained for an additive revision. Nothing has been hashed, parsed, executed, queued, or admitted by authoring this packet.

The controller pins the exact Python executable and every `unittest` Python source under the held common mutex. It imports a fresh immutable source-only copy of that package, with no preloaded `unittest` modules or copied bytecode, verifies every loaded module's identity, and defines the result recorder only after those checks. The exact29 fixture catalog is unchanged. Diagnostic normalized values and expansions are retained as gated source proposals with unresolved diagnostics; they never establish source or chart admission. All available failed/early/late raw and receipt bytes have separate terminal pins, including failures after a saved passed fixture receipt.
