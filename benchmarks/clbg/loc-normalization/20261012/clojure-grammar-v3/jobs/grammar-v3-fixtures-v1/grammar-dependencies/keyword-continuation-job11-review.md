# Continued declaration ownership after job11

This additive proposal preserves frozen source bytes, measurements and producer
counts. It is not admitted until a later common-mutex fixture and exact-source
pass. Job11 already provides the source identities and diagnostic positions;
this document does not claim a new executed source hash or count.

The approved rule counts independently named declarations separately, with
formal groups and call/data arguments structural. A complete continued name
list with a scalar typed declaration receives one source unit per declared
name. Its formatting newlines do not create extra statements. A literal or
array initializer spanning rows is left in the previous data-wrapping path.

The same static review identifies Ada `overriding` and `not overriding`
modifiers written above a routine signature. They belong to that one header;
recognizing them prevents a following function body from incorrectly closing
its enclosing package. A proved package's `private` marker is a declaration
section opener with no new lexical scope/close. Unowned private markers stay
gated. A complete written pragma group counts once with its name/settings as
structure, while malformed groups stay gated.

A written named close owns its optional loop name or qualified definition
name, including formatting rows, as one explicit close. Qualified definition
names must agree with the proved definition header. An Ada named loop identifier
and colon belong to its one loop header, consistently with the earlier approved
Fortran named construct rule; a mismatching written loop close stays gated.

The task proposal owns only bounded task type/body/single-task headers, forward
declarations, typed discriminant/formal profiles, entries, and accept statements.
Task/accept bodies expose independent statements and their written end. No
implicit close is counted for a forward declaration or simple accept. Ordinary
selective-accept alternatives prove an accept/terminate lead and a real branch
boundary. Boolean `or` inside an alternative assignment/call does not create a
branch. Task interfaces, protected/generic/access-subprogram/extended-return and
timed/conditional/asynchronous select variants remain gated. Unknown profile
content cannot be protected merely because its parentheses balance.

Pascal class routine modifiers, static/inline suffixes and signatures belong to
one written header. A record's routine prototype does not create a body or close
that was not written. The separately written class-method implementation exposes
its body and end. `with ... do` is a control header; a written begin adds zero and
its written end counts once. Class/type/exception syntax beyond those exact
owners retains the prior gate.

Complete Ada based literals reconcile Pygments' known Error tokens for the #
delimiters only when every digit fits the stated base and the complete literal
owns the exact span. Unproved # delimiters also receive an explicit grammar
diagnostic, because actual job12 showed that Pygments may accept an invalid
numeric spelling without Error tokens. The invalid-syntax gate requirement
remains fixed; its fixture no longer assumes a particular lexer token kind.
Other lexer failures remain intact. String/comment spans
are never restored. The actual binarytrees literal `16#100#` is covered by this
general numeric grammar; its program is not otherwise certified by that fact.
Fortran standalone private/public access semantics remain explicitly review-
gated until a consistent attribute/section-unit decision is recorded.

Thirteen new fixture methods compare packed/continued/expanded declarations,
headers, profiles, controls and literal masks. Static peer review required exact
balanced bounds before initializer classification, typed-profile proof, real
alternative boundaries and named-loop header ownership; those draft issues
were corrected before any execution. Named arguments, formal and wrapped data,
unowned private/malformed pragma, name mismatches, unknown attributes/interfaces,
unknown callbacks/select variants and invalid numeric literals remain protected
or gated. No fixture execution occurred while this proposal was authored.

retain gates. Two new fixture methods compare packed/expanded source and retain
