# Thirty-one original-reader fixtures: owned runner candidate

Source only. No imports, hashing, parser or fixture has run. Root must review
the actual SWI bootstrap version, ARM64 image closure, private home and mount
cleanup before supplying a `reviewed-actual-swi-scanner-runtime` descriptor.
This descriptor authorizes scanners only, names a review identity, binds the
actual bootstrap report/terminal hashes and runtime binary/environment, and
has no unresolved entries. It pins exactly the projector, fixture, scanner,
runner, this review and selected Python executable. No benchmark is loaded.

`run_fixtures.py` takes those explicit artifacts and creates a fresh evidence
directory after obtaining the original common timing mutex. It reuses the
unchanged bootstrap loader and the already fixture-qualified general C3
owned-command service. The complete actual bootstrap source/image corpus,
sealed preparation/service and fixture source bytes are verified before cold
loading. Native scanners inherit the common descriptor, use new process groups
and retain actual identity, exit status, stdout/stderr and cleanup journals.
The selected Python's unittest `.py` package is copied and pinned under the
same lock before import. All unittest module origins must remain inside that
fresh snapshot after import, discovery and execution, including interrupted
runs. Both actual original and snapshot bytes remain terminal input pins.

Original31 bodies/IDs stay byte unchanged. The freshly loaded fixture module's
subprocess reference is a local facade, never a global subprocess patch. It
permits only the exact scanner argv and unchanged twenty-second/FD policy.
Parser-error cases retain the service's original nonzero receipt/exception;
only a clean actual nonzero reader exit becomes CompletedProcess. Timeouts,
ownership and cleanup failures cannot masquerade as parser errors.

Each scan first archives every original temporary `.pl` input and its actual
path correspondence, preserving helper/context fixtures after their temporary
directory closes. A local result observer saves original source bytes, raw AST
packets and every returned owner/event projection without altering results.
Exact31 discovered and started identities, no skips/errors/failures/expected
failures/unexpected successes and unchanged input pins are mandatory. Raw logs,
partial scanner/projection evidence and terminal receipt pins survive failure;
no retries or source-count/chart admission follow from this fixture receipt.
Discovered/started IDs and a live result's partial counters are saved even when
an exception interrupts execution. Artifact pins accumulate per path; a failed
read records an integrity error while preserving every other readable artifact.

The later original22/20 replay and source-owner semantic review are separate.
This runner has no runtime installation, benchmark timing or publication path.
