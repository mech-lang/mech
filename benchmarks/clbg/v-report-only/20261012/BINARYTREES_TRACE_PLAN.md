Draft only; no build, native probe, fixture execution or full timing is launched by these files.

`binarytrees_trace.py` emits separate unscored copies of the two `revisions/input-v2/sources/binarytrees` sources. Its exact anchors preserve the original `Node` declaration, both `create` return expressions, `check`, every production `sum += check(tree)` statement, every printed expression, and all real depth/count/thread work. It names the ignored temporary loop variable to observe the real global iteration index. It constructs no additional `Node` and adds no field, heap annotation, substitute allocator or production arithmetic. The ordinary V observer traverses real addresses and writes one file per root; optimized workers do not share a mutable map or trace stream.

Root's existing native ownership wrapper will build each observer copy with the same compiler, GC and optimization flags as that source, then run N=6,7,9 under the common timing mutex. `MECH_V_TREE_TRACE` points to a fresh existing directory per profile/case. Every actual root receives its own fresh `map[u64]bool`, which rejects repeated nodes, shared subtrees, cycles, missing children, nonleaf leaves and nonnil leaf edges. Address conversion follows V's standard pointer-to-`usize` operation inside an explicit unsafe conversion; it does not dereference synthesized pointers or invoke C. The pinned V0.5.2 builtin `map.v` uses the same pointer-to-`usize` conversion. Actual compiler/type/output behavior remains unqualified until root's bounded run.

There are three root observations beyond the prescribed temporary roots: stretch after real construction, long-lived immediately after real construction, and the same long-lived forest immediately before its final original check/output. The independent Python reconciler reconstructs every root from its edge list, requires exactly 2^(depth+1)-1 distinct real addresses including leaves, exact iteration indices and original cumulative sums, and all original stdout bytes. Before/after retained graphs must have the same root address and every edge. No temporary graph may share an address with the live retained graph.

Maps contain scalar addresses only. The observer does not retain temporary Node objects, so it allows address reuse across different temporary roots. It does not claim a globally unique address for every allocation, an allocation count in the uninstrumented optimized binary, or timing equivalence of this observer. The root should additionally retain generated-C/allocation-call evidence from the unchanged measured source if needed to establish GC allocation lowering. Instrumentation's extra traversal/files/maps and any resulting liveness effects are explicitly unscored. Full studies use only unchanged source bytes after independent work and output gates pass.

Source/public API provenance remains the previously pinned V0.5.2 commit `7647ce1c6fad63b5578bc07883139906de74b2f8` and published ancestry in input-v2's profiles/history. No builder, chart, website or language-list hook is added.
