# Combined frontend v2 source release

This fourteen-file additive packet starts from the current published
`overview/explorer/dist` UI, whose app/index version is
`20261013-samples`. It composes the qualified formatted-LOC and recorded
platform features from `combined-ui-v1` without replacing the current layer
implementation. It is source-only: no imports, parsing, tests, hashing,
browser, native commands, freeze, deployment or dataset edits occurred.
Canonical dist, the website and all immutable producer packets remain unchanged.

Exact files: `app.mjs`, `index.html`, `math.mjs`, `rankings.mjs`,
`style.css`, `mech-palette.css`, `traits.mjs`, `platform.mjs`,
`formatted_axis.mjs`, `test_combined_axis.mjs`,
`test_layer_controls.mjs`, `test_median_rankings.mjs`,
`test_year_window.mjs`, and this `REVIEW.md`. No data or downloadable
benchmark assets are copied into the source packet. Root must stage these nine
runtime assets alongside the existing complete dist assets and its qualified
candidate data. Browser module/style versions consistently use
`20261013-combined2`; imported platform has no previous published cached version.

The current independent Samples, Medians and Density Off/Dim/Highlight modes
remain. Their state is retained through source navigation and Back. Raw
recorded runs still supply Samples and the previsibility density population,
with one vote per actual program/run. Repeated equal elapsed values remain
distinct. The removed faint background benchmark-endpoint loop stays removed:
Samples Off does not reintroduce an endpoint cloud. Benchmark/profile medians,
connectors, labels, covariance, global summaries and release history remain
within the separately controlled Medians layer. Fastest/Fewest profile toggles
do not change run density. Density does not change the chosen axes framing.

The current compact two-chart rankings renderer is retained, including fixed
readouts, one-decimal summaries, exact coordinate-median/log-SD calculations,
nonoverlapping dot lanes and source navigation. Its only renderer delta is an
optional LOC title, supplied by the selected metric. The full inclusive
release-year window, eight decade presets, playback cursor, language/family
overview, selected-source comparison, source navigation and return controls,
run-to-run SD, cross-benchmark log-coordinate medians and keyboard interactions
remain. Hover information stays in the fixed scrollable strip outside the SVG.
The interface continues to express measured time relative to the benchmark's
fixed best-time baseline.

Canonical projection returns its original data object. Formatted projection
requires complete qualified positive whole-bundle counts and separately
published positive formatted X. Missing/unavailable/failed/pending counts and
missing coordinates remain null and never use canonical LOC as a substitute.
The comparison and shared-benchmark paths reject nonpositive/nonfinite source,
time and X/Y values before statistics. The producer's full eligible
whole-bundle formatted minimum supplies the formatted baseline, independent
of display filters. Source/time/baseline records are not rewritten.

The metric selector and omission note stay in the common toolbar, available
in Rankings too. Language tables list original canonical and separate
formatted counts, all actual timing runs and SD. Unsupported sources remain
inspectable. The inspector shows status/reasons and clears unavailable content
instead of leaving an old source displayed. Explicit comparisons use the
selected inventory program in a pure view copy; unavailable formatted sources
contribute no coordinate. Back restores the saved metric and controls.
The canonical/formatted domain and release-history caches include the metric.
Medians framing retains its compact range; All samples includes every eligible
run and covariance envelope, including complete highlighted inventory.
Both source metrics share the canonical/formatted Y envelope for fixed time
framing on metric switches. Layers, year, language, profile and program
visibility do not move it. The single-benchmark legend names the selected LOC
baseline instead of displaying a canonical baseline under formatted axes.

The reviewed `platform.mjs` and `traits.mjs` are copied intact. Platform
choices JVM/BEAM/.NET/Native/JavaScript/Unclassified consume qualified pinned
original report/runtime/source evidence and separate historical confidence;
language names/extensions never classify measurements. The complete merged
source catalog participates in consistency checks independently of LOC and
visibility. Missing/conflicting evidence stays Unclassified; proved platform
may survive a separately unknown execution mode or historical executable bytes.
Shared chart/inventory records must agree on source/time/coordinates plus
`measured_backend`, `execution_mode` and all five formatted fields.
Resident sample columns and sorting use the original resident mode or the
adapter-preserved `prior_runtime_metadata.fields.execution_mode`; actual
sample details and whole-process measurements stay unchanged.

The existing three layer/ranking/window assertion scripts are source copies
from the tested layer-controls packet. The existing combined-axis script
is adapted to actual-run density rather than the old profile-position density.
It retains meaningful projection, missing-coordinate, preservation, source
inspection and platform conflict assertions, adds all layer-mode combinations
over the projected actual-run population and separate historical uncertainty.
