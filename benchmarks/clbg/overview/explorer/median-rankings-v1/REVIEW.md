# Current canonical chart views candidate

Mutable source-only UI candidate copied from the released year-window-v1 six-file UI. It contains no data copy, changes no published dist, and has not been executed, parsed, tested, hashed or frozen by its author. Root owns actual QA and publication against the current immutable canonical dataset, SHA 4fe402c21360fbbbe9d650c15d1fd4c62422c17cfad8cafd24721fe7f0bd2947. Existing timings, canonical coordinates, baseline normalization, source records, program inventory, year sources and trait definitions are unchanged.

Release window retains the accepted inclusive lower/upper selectors, decade choices, playback and saved navigation state. This packet additionally separates the two native thumb hit areas vertically by 20 pixels at all positions, including equal years, with a 54-pixel container. Keyboard semantics and non-crossing clamp remain unchanged. The first-year handle is above the shared track; the last-year handle is below it.

Median rankings derives Speed from entry.fast.y and LOC from entry.small.x in currentEntries, after existing benchmark/language/trait/year/program eligibility. Each eligible execution variant votes once. It uses the chart's exact ratio-coordinate median, sample SD of log2 values about their log mean, and signed z distance from log2(median). Ties appear once in a separate section. Side bands include |z|≤1, then 1<|z|≤2, 2<|z|≤3, and extend dynamically. Stronger departures sort first within each side. Zero spread and empty selection have stable output. Partial benchmark coverage is explicit. Language navigation uses the existing saved origin state, so Back restores rankings and filters.

recordedSamplePoints collects actual positive recorded elapsed values once per enabled measured program key, normalized by the unchanged benchmark baseline. App callbacks bind language and benchmark to the current eligible entry/input; normal views use admitted input.programs, highlighted language overviews use their measured full catalog, and explicit source comparison uses the existing selected-source replacement. It does not inspect profile or global controls. Samples is enabled in every chart view and controls recorded runs exclusively. Benchmark profile median marks and Mech benchmark pairs depend only on the Fastest/Fewest LOC controls, so hiding Samples preserves them. Raw runs have explicit sample/run/source tags and their own CSS opacity; median/profile toggles do not remove them, including both profile controls off. Global focus may dim profile medians; raw samples stay visible. Hover still dims other languages. Means-focus may intentionally clip outlying runs to the existing fixed domain. Navigation retains the user's Samples choice rather than silently forcing it on.

Density uses distinct enabled fastest/fewest-LOC mean positions. Each execution variant has total weight one, divided across its distinct positions; coincident profiles contribute once. Actual runs never feed this field. A Gaussian is sampled across every cell of a 48×36 log2 grid on the fixed full chart domain, with 1.25-cell bandwidth on each axis. Legend states variant/position counts, equal weights, bandwidth in log2 doublings, and relative square-root-scaled intensity. It is a weighted smoothed intensity, not a probability-normalized estimate. Empty profile populations retain a clear full-grid background and explanation; independent Samples can still render. Heat cells have no pointer events, preserving profile/source/language navigation above them. Year/trait/benchmark/language/disabled-program changes recompute the population without moving baselines.

Focused pure assertions in test_median_rankings.mjs cover even coordinate median, sample log SD/z, inclusive σ boundaries, ties, zero spread, far bands, selection-derived inputs, disabled/pending programs, independent/deduplicated runs, equal density weights, coincident profiles, full/empty grid and smoothing symmetry. test_year_window.mjs is copied unchanged from the accepted year-window packet.
