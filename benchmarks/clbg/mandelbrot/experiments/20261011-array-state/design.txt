The scalar prototype packages zr, zi and iteration as a numeric row array. It
calculates both coordinate components and both squares with existing array
operators, then commits one whole next-state value. That is a single array
update, rather than several scalar assignments placed on one line. The radius
test and stop predicate remain separately authored bindings. The array's third
square is unobserved and can be removed by the existing live-root traversal.

The lanes prototype uses an 8x3 numeric array and the same single recurrence.
The five-step prototype uses an 8x2 array plus a scalar iteration counter;
Advance is an ordinary pure Mech function, and four ordinary function-application
stages compose it after the first recurrence. Its escape-observation interval
matches the frozen 29-line fast source. The first step reuses the radius squares.

Concrete current gaps for a Uiua-like whole-row record formulation:
  1. grid/map-until accepts only scalar or fixed column vectors with 1-64 lanes
     (src/engine/src/native_sequence/grid.rs:233-240). A runtime-width row is
     not an admitted input, although the language supports dynamic matrices.
  2. The native map runner requires each state slot to borrow as f64 storage
     (hosts/gpu/src/fused_f64/map_runner.rs:125-137). FusedProgram::shape accepts
     only fixed-shape f64/bool scalars/tensors and rejects records/tuples and
     dynamic dimensions (hosts/gpu/src/fused_f64/mod.rs:1697-1735). The source
     language's record syntax and updates therefore do not by themselves give
     this native grid path a Uiua record loop.
  3. The maintained logic catalog offers elementwise and/or/not/xor but no
     Boolean any/all reduction. stats/sum is numeric. The 8-way OR is therefore
     explicitly authored here. A generic any/all operation would remove the
     lane-count-specific selector expression, even though physical LOC remains
     one binding either way.
  4. FusedProgram::lower currently rejects control nodes. sequence/iterate
     already exists in another native array/source-callable frontend, but it
     cannot yet be used interchangeably inside this fixed-shape grid compiler.
  5. The retained driver predates multiline arrow-block handling and rejects
     local mutable state. This gap is resolved in the current compiler by a
     generic statement classifier: assignments and augmented assignments remain
     statements, RHS pipelines are lowered once, and a final mutation returns
     the updated whole local base after conversion/selected writes. Comparisons,
     ranges, strings and nested selector expressions keep their parser meaning.
     A final context/resource target without a local base is diagnosed. No
     benchmark-specific normalization or native operation was added.

Useful generic work, subject to compiler/source pin coordination:
  - Add Boolean any/all reductions to the maintained source/runtime/native
    catalogs and lower them to mask reductions in the fused backend.
  - Flatten record/tuple leaves into typed native state, preserving simultaneous
    whole-state updates, field access and stable state reset. This is generic
    structural scalar replacement rather than a Mandelbrot host operation.
  - Connect pure source-callable array iteration/control IR to the grid backend
    so a dynamic row recurrence can be fused and tiled; eliminate temporary
    arrays and keep lane state and persistent live masks in native storage.
  - Automatically widen independent scalar grid recurrences and support
    vector predicates with persistent per-lane masks, retaining every required
    observation. That would let concise scalar authored code use SIMD without
    a source-level lane count.

Closed-map dead-state-leaf elimination, possible proof and limits:
  - Restrict this transform to a native map whose externally observable ABI
    contains only declared output/stop values. Resident snapshot, serialization,
    debug/display or whole-frame state exposure makes the corresponding leaves
    observable and must mark them live (or reconstruct them exactly).
  - Begin a backward slice at every externally observed result and the stop
    predicate. If an instruction reads a state leaf, retain that leaf and the
    instruction producing its next value. Repeat through state update edges to
    a fixed point; a whole-value state assignment must not make every updated
    leaf a root automatically.
  - A removable leaf cannot affect a retained next-state value, predicate,
    output, side effect, error/termination behavior, dynamic selector, aliased
    reference or externally inspectable cell. Unknown indexing/alias/effect
    cases conservatively keep the affected state. Floating-point rounding and
    ordering of every retained operation and immutable capture stay unchanged.
  - Preserve the initial/reset value of every retained leaf and all predicate
    observation points. Predicate-before-commit behavior must remain intact;
    deleting unused state cannot imply deleting an intermediate predicate.
  - Here, only iteration row leaf [3,1] affects done. The seven other counters
    feed only their own +1 updates and do not affect real/imaginary recurrence
    or outputs. Their iteration-square values are already removed by existing
    live-root instruction traversal; the counter updates remain roots today.
    This particular closed native ABI permits dropping those seven leaves.
  - Proven loop-state equivalence is another option: identical seeds and
    structurally identical recurrences over equivalent operands permit sharing
    a value while reconstructing exposed duplicates if needed. The proof
    cannot assume equality merely because runtime samples happened to match.
  No backend transform has been implemented in this experiment.

Automatic loop unrolling must retain the predicate check after each semantic
iteration unless the source explicitly selects chunked observations. Arbitrary
map recurrences cannot safely skip checks merely because this Mandelbrot source
uses a five-step interval. The factored Advance prototype expresses that choice
in ordinary Mech source today, without adding a benchmark-specific primitive.
