This review covers all twenty unchanged application sources selected by the
private-v5 preparation. It is a source review, not a claim that the preparation,
tree observers or full samples already passed. Full manifests additionally
require the actual passed prerequisite reports and their exact source/binary
identities. Workload helpers are counted as application code; the generic
privately pinned GMP ABI/name adapter is audited separately.

Regex redux: compact calls PCRE independently for each of the nine canonical
nonoverlapping patterns. Optimized divides those nine pattern indices among
exactly eight ordinary joined threads, each counting actual findBounds calls
and advancing to the previous match's last index plus one. Each result belongs
to one disjoint index. Parent output follows the join loop. Both sources remove
headers/newlines once and perform all five ordered replacements on the previous
replacement's whole result. Case sensitivity, header EOF, repeated matches and
replacement boundaries are covered by the exact retained bounded fixtures.
The private header-mode PCRE1 binding has its own actual version/layout probe.

Reverse complement: compact applies the complete IUPAC mapping while ingesting
each record and reverses the actual completed string. Optimized stores each
record and swaps/complements symmetric characters, including its middle
character. Both preserve header ordering, clear after each record, ignore
comment lines, parse CR/LF/CRLF and emit every complete/partial60-column line.
No fixed sequence, input-size shortcut or generated answer is present. Empty,
header EOF, mixed-case IUPAC, comment and tail cases are retained independently.

Pi digits: both sources form separate3*q+r and4*q+r numerators and perform two
actual integer divisions before comparing the quotients. Accepted digits use
the old q/r/t production recurrence; consumption uses k and2*k+1. Every digit
and complete/partial output line is produced. The pure generic library floors
signed division; GMP's public mpz_tdiv_q truncates. Fresh actual candidate-state,
numerator and quotient traces prove nonnegative extraction operands at every
accepted/rejected candidate, where both conventions coincide. Zero/1/9/10/11/
27/97-digit traces, generic signed primitives, GMP destination aliasing, LP64
layout and complete output are independent required prerequisites. Neither
division is replaced by a remainder, cached digit or special benchmark helper.

Spectral norm: the denominator computes the triangular dense matrix entry from
both indices. Every multiply visits all N columns for every output row.
Twenty successive A-transpose-A products execute forty dense multiplies in
ten alternating u/v iterations. Both actual final dot reductions include all
N components. Optimized assigns contiguous disjoint row intervals to
min(8,N) threads and joins every thread before the dependent multiply starts.
The full arrays remain owned by the parent until every joined worker exits.
N1/2/3/5/9/100 exact outputs check minimum, odd and uneven shapes. No sparse,
closed-form or fixed-result substitute exists.

Mandelbrot: compact computes requested coordinates from2/N, starts z at zero,
performs up to fifty escape steps per requested pixel and writes every PBM bit.
Optimized assigns disjoint requested row intervals to min(8,N) threads. Each
byte computes only its valid lanes, advances those lanes uniformly in groups
of five steps, stops a group only when every valid lane is outside, and creates
the final byte from actual squared states. Already escaped lanes may do extra
work within a group; this is reported as ordinary grouped work. Parent emits
the actual requested dimensions and image only after all joins. Widths1/2/3/
7/8/9/15/16/17/31/65/129 and N200 complete PBMs independently check every byte
and zero tail padding. No fixed extent or digest-based answer exists.

FASTA: both sources build binary64 cumulative probability tables from the
canonical probabilities, advance the shared seed for every random symbol by
(seed*3877+29573) mod139968, divide by139968 as binary64, and scan the cumulative
table for the selected symbol. The same mutable seed spans IUB and Homo.
The ALU sequence is cycled for2*N symbols, then3*N and5*N random symbols are
generated. Compact emits actual lines; optimized changes buffering only.
Both preserve60-column wrapping and final partial lines. N0/1/2/29/30/31/60/
61/287/574/20000 complete byte oracles cover all wrapping and generator seams.

K nucleotide: both parse the exact THREE token boundary, select its record,
ignore comments and stop at the next header. Compact counts actual overlapping
string windows. Optimized rolls a width-specific2-bit key into a growable
table for each of widths1/2/3/4/6/12/18, with one joined ordinary worker per
width. No fixed table cardinality is assumed. Fresh ASAN audit copies dump all
seven completed actual tables, including first-two frequency maps, reconcile
every overlapping window and reset parent-owned tables after all joins. The
separate seven-worker ORC fixture tests empty/tail/growing map and string handoff
and parent destruction. All twelve bounded input cases per source remain tied
to the original executable fingerprint, including exact token/control/CR and
zero-byte inputs. There are no precomputed DNA counts or skipped maps.

Binary trees: both creators call new for every node, including every leaf, and
recursively create two distinct children when depth>0. Actual check traverses
those nodes and counts each node. Each requested depth creates the stretch,
retained long-lived root and every prescribed iteration tree. Optimized gives
each depth's iteration range to at most eight ordinary joined workers; each
worker builds/checks/destroys its own iteration roots and writes one integer
total. Full manifest admission additionally requires actual live graph/node/
leaf observers at N0/4/7/9, exact disjoint worker intervals, all joins and the
same retained long-lived graph before/after churn. Observers retain only
temporary integer addresses. The unchanged scored creator's generated C and
final ARM code must independently retain real allocation, both child calls and
the leaf branch. Audit-copy observations make no scored timing or GC-pressure
claim and cannot replace scored allocation evidence.

Nbody: both hold the canonical five bodies with their original masses, positions
and velocities, offset the sun's momentum, visit the ten unordered body pairs
on every advance, update both velocities and then all five positions, and
evaluate both initial/final energies. The optimized source copies the actual
pair bodies into local ordinary values before the same operations. Both execute
the requested number of ordinary0.01 steps; no approximated trajectory or
closed-form energy is used. Floating contraction remains disabled by pinned
compiler flags. Independent N0/1/2/10000 output validation uses the established
binary64 energy tolerance; full N50000000 output is checked by the same harness.

Fannkuch redux: compact enumerates all factorial(N) ranks by canonical prefix
rotation/carry digits. Each rank copies the actual permutation and performs
each prefix reversal until the first entry is zero, then adds its flip count
using global rank parity and updates the maximum. Optimized initializes each
worker's actual permutation/carry digits from its global first rank using
factoradic rotations, executes its disjoint contiguous interval, and uses the
global rank in checksum parity. The parent launches min(8,factorial(N))
threads, joins them and reduces their actual checksum/maximum values. Complete
N1 through N8 outputs include odd worker starts, uneven partitions and rank
boundaries. Full N12 checksum3968050 and maximum65 are independently prescribed
outputs. No permutation, flip loop, rank interval or checksum is elided.

Every application launches one fresh native process with its exact source,
executable, compiler/package/runtime and environment pins. Existing twenty
native sampler gates reject incomplete output, exit/resource/power changes,
monitor/cleanup errors, competing compilers or changed pins. The common timing
mutex covers every compiler, observer, pin sweep and full sample, including
sampler/native descendants. All failed attempts remain immutable and prevent
automatic retry. Canonical LOC comes from the separate qualified root audit;
full samples may carry null LOC until that exact immutable overlay is ready.
