This is the source/proof review package for parent approval, not an assertion that the unbuilt programs are qualified. Exact application/helper identities are frozen by the guarded proposal. All twenty compiled_source_bundle lists include every authored C3 source, helper and ABI declaration supplied to their compiler invocation. Generic vendor libraries are separately pinned and linked only in the relevant profiles.

`support/buffer.c3` contains only growing byte storage/I/O. `support/threads.c3` wraps exact std::thread Thread.create/join, preserving parent job/thread storage through joins. `support/gmp.c3` exposes generic LP64 integers/arithmetic/version ABI; no Pi computation lives in it. `support/pcre2.c3` exposes the generic 8-bit regex API; no regex workload kernel lives in it. Every relevant declaration/glue line belongs to the scored source bundle.

Pinned std::collections::map dynamically allocates entries and replacement bucket arrays. The selected explicit `&allocators::LIBC_ALLOCATOR` is the official immutable allocator whose POSIX implementation calls libc calloc/malloc/free. It holds no temporary arena or thread ownership state. Maps remain distinct parent-owned fields; workers write exactly their assigned map, main traverses/free only after each actual join. Source-work observer requires the exact allocator pointer and preserves every actual map entry/capacity/window-total reconciliation. It records no per-window event stream. The exact reviewed production nested-start loop or rolling-index/warmup loop establishes window traversal; native complete maps and totals are independently reconciled against all Counter windows.

All source observers are additive unscored copies. Their output is reconciled against independent recurrence/Counter/graph checks and the original complete expected stdout. Source anchors are unique and replacements leave the production recurrence/creator/window update/check code unchanged. Original scored source and binary hashes bind each proof; LLVM and final ARM receipts are from the original scored tree binary rather than the instrumented copy. Meaningful corruption fixtures reject substituted second Pi division, missing map window, default/fixed table growth, substituted owner, removed real leaf, changed retained graph, churn overlap with the concurrently retained graph, worker interval/iteration-label substitution and allocation after any preallocation branch/return. Released stretch addresses may be reused normally.

All mandatory source/process/environment/integrity checks run under the common mutex. None of the observer or bounded-run times is admitted as performance. Subsequent full studies use the exact qualified source/binary/runtime/helper/work pins and frozen twenty-gate guard, three rotated rounds and fresh unchanged current Mech control. Ordinary clean source failures preserve failed profiles and continue independent rows; failed/partial profiles remain unscored and keep completion pending. Independent canonical C3 LOC remains null until qualified.
