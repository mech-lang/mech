The counted helper configures standard I/O to Latin-1 binary mode before bounded raw reads/writes. The official IO documentation warns that default Unicode stdio corrupts raw byte operations; actual all-256-byte, NUL, CR/LF, lone ESC, EOF, multi-chunk, and large pipe round trips are mandatory. Whether the selected noshell/noinput launch configuration provides the intended stdio service is an actual fixture gate, not an assumption. Regex compilation requests neither Unicode nor case-folding; all nine count passes and five sequential replacements remain authored Elixir loops. Record the exact OTP `:re` implementation and configuration from actual pinned runtime evidence; do not infer a separate regex JIT. [IO byte API](https://elixir.hexdocs.pm/1.20.4/IO.html), [tagged Regex wrapper](https://raw.githubusercontent.com/elixir-lang/elixir/v1.20.4/lib/elixir/lib/regex.ex).

`Clbg.Support.fixed` decodes the original IEEE binary64 bits, computes the exact scaled integer fraction with Elixir arbitrary integers, and rounds ties to an even quotient. It preserves a negative sign when the rounded result is zero. This is an authored general formatting helper; the proposed source proof does not replace actual rounding/output fixtures. No benchmark loops are moved to a host kernel. Every binarytrees node, including leaves, carries a fresh `make_ref()` and the long root passes through the whole short-tree study to its final traversal. `make_ref` is a general VM identity primitive; compiled allocation and retention must be demonstrated separately.
