# Language overview interface — source review

Status: implemented source only; root review, syntax checks, dataset checks, browser QA, checkpoint and Site publication remain pending. This work did not execute imports, parsers, tests, formatters, builds, hashing, benchmarks, browsers or Git. It did not edit data.json or the Site checkout. The original app.mjs, index.html and style.css are retained in the exclusive baseline directory before these edits.

The separate sidebar checkbox continues to select a language or family. Its adjacent name is now a button that opens the language overview. Parent names such as Mech show the measured execution variants together; variant names open that variant alone. Comparison-table language names and aggregate chart labels also open the overview. Benchmark labels on the highlighted chart open their program inspector.

The overview restores all ten workloads, all release years, no trait restrictions and all programs. Selected language variants are persistently highlighted against the existing cohort context. Fastest, fewest-LOC, samples, coordinate medians and covariance start enabled, with Focus on means disabled. All retained program medians and actual individual run coordinates are plotted; run Y is recorded elapsed seconds divided by that workload's existing fixed baseline_seconds. No source coordinate jitter, sample duplication by aliases, surrogate measurements or fabricated missing workload values are introduced. Deduplication is by catalog key. Coincident actual coordinates can overlap visually; every run remains separately listed numerically.

The optional qualified data.program_inventory is merged into a separate UI catalog, with existing data.programs taking precedence for shared identities. The canonical data.programs, benchmark groups and comparison/math baseline inputs are not mutated. Inventory rows without x/y use the existing benchmark LOC/time baselines. If no full inventory is present, the overview clearly states that the publication retains its fastest/fewest-LOC pool; it does not invent discarded programs. Source files are read from the existing published file catalog. Root must verify every admitted inventory identity, score, sample, source file and timing report against its qualified packet before publication.

Diamonds summarize each execution variant's actual per-benchmark fastest or fewest-LOC endpoints with equal benchmark weight. Their 1σ/2σ covariance uses the existing sample covariance across benchmark log2 coordinates and is translated from the geometric-mean center to that coordinate median. These are across-benchmark statistics, not run uncertainty. The usual mean-centered contours are not drawn simultaneously with the translated ones in this view. Disabling the median overlay restores the normal mean-centered contour, while the per-language oval control still governs that variant's covariance visibility. The per-program table and inspector separately show recorded run-to-run timing_sd. No SD is derived from unavailable values.

The language-view domain includes every retained program median, positive recorded run, original covariance boundary and translated median covariance boundary for the selected language. It preserves fixed normalization baselines while allowing actual runs and contours below the cohort's 1x median baseline. Normal summary, benchmark and Mech chart domains remain routed through the existing chartDomain function. Toggling profiles or covariance does not recompute the dedicated view's domain.

Every workload stays listed in the table, including explicit coverage gaps. Each actual source row includes its median, recorded SD and all numerical runs. Program buttons open the existing source/timing inspector. Previous/next navigation walks the retained language inventory across workloads and variants. The source selector, actual code and SHA/report fields are retained. Inventory-only programs cannot pretend to be enabled canonical endpoints in the main comparison.

Comparison controls select an execution variant, workload and another measured language. Row/inspector Compare actions select that row's actual language/workload. A missing comparison timing is stated explicitly. Back to language overview restores the originating source detail, including its file index when open. Back to previous chart restores the saved selections, disabled programs, profiles, contours, detail and inspector-open state. Ordinary sidebar filters and chart tabs intentionally leave the overview.

The fixed above-chart hover strip and its clearHoverDetails/showHoverDetails behavior are preserved. Its vertical alignment now uses safe center so wrapped details can scroll from the top. No floating tooltip is reintroduced.
