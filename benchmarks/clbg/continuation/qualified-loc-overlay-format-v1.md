# Proposed exact-source LOC overlay

This is an importer contract proposal, not a qualified count receipt. Count/source replay and all hashing run under the common timing mutex. Preserve the original replay proposal and producer LOC; qualification creates a separate overlay. Timing manifests/reports stay immutable.

Each language overlay supplies `schema_version: 1`, `language`, `status: qualified-exact-source-LOC`, `profile_count: 20`, `complete_authored_source_bundles: true`, `unresolved: []`, `normalization_policy`, `fixture_receipt`, `replay_receipts`, `grammar_snapshot_pins`, `compiler_bound_input_inventory`, `profiles`, `pins`, `canonical_LOC_admitted: true` and `chart_admission: false`. MATLAB's separate two-source correction uses `profile_count: 2` and an explicit scope. This status is valid only after actual count replay and source-specific semantic review pass; Crystal's completed LOC18 replay remains a source proposal until its semantic ownership review and compiler-bound inventory qualification pass.

`fixture_receipt` is `{path, sha256, status: passed}` from the immutable qualified grammar snapshot. `normalization_policy` identifies the precise policy/version and evidence path/digest. `replay_receipts` bind every actual source/helper count output by path/digest. `grammar_snapshot_pins` contains the exact frozen modules, fixtures and lexical dependency pins used in those replays.

`profiles` is a map keyed by each measured profile's exact `id`. Every entry contains:

- `benchmark`, `variant`, `source`, `source_sha256`, `producer_loc`, `physical_loc`, `canonical_loc`, `expansions`, `source_bundle`, and `semantic_review`. Profile `physical_loc` is the exact sum of its bundle-file physical counts; `expansions` retains the actual independent-boundary additions and source/span ownership rather than only a total.
- `source_bundle` is an ordered array matching the authored application inputs supplied to the compiler/measurement. Each item contains `path`, `sha256`, `role` (`application` or `application-helper`), `physical_loc`, `normalized_loc`, `count_receipt`, `ownership_review`, and `unresolved_diagnostics: []`. The main application is first. Count each distinct bundle file once per application; a shared helper counts in each application that includes it.
- `count_receipt` binds the actual replay path/digest and exact source row identity. `ownership_review` and profile-level `semantic_review` are `{status: passed, review_identity, evidence_path, evidence_sha256}`. Any parser diagnostic must have a source/span-specific disposition in that evidence; no unresolved diagnostic or blanket language waiver is admitted.
- `canonical_loc` equals the sum of all bundle-item `normalized_loc` values, with exact integer checks and no estimate/producer-count substitution. `producer_loc` preserves the producer's existing value, including null.

Bundle completeness must be checked against a separately authoritative compiler-bound application input inventory. The exact importer field is `compiler_bound_input_inventory[id] = {status: qualified-exact-authored-compiler-inputs, source_sha256, binary_sha256, evidence_path, evidence_sha256, files: [{path, sha256}]}`. Its evidence is separately pinned and derived from the retained compiler invocation/package inputs and qualified source/support packet, with an explicit source-role review. An overlay's own bundle list is never proof of completeness. A measured row with missing/empty `source_bundle` must provide that separate authoritative inventory; an importer cannot skip helper equality or assume a singleton in that case.

For Crystal's current twenty applications, each bundle contains its exact single scored `.cr` source; work/primitive observers are excluded. C3's bundles must include every locally authored helper/ABI declaration passed in `source_bundle`/`compiled_source_bundle`, including buffer/thread/GMP/PCRE glue as applicable. Nim and Pony must use their qualified compiler input inventory rather than assume one file. Generic vendor standard libraries, compiler/runtime binaries, and uniformly excluded stream-only runtime launchers are pinned separately and do not become application LOC.

`pins` binds the complete overlay evidence, authoritative compiler input inventories, all scored bundle files, actual replay artifacts and semantic reviews. An importer requires exact twenty measured IDs for a full language cohort, matches each bundle/hash to the independently reviewed compiler-bound source/helper inventory, checks every source digest and evidence pin, requires all semantic dispositions and qualified grammar receipts, and recomputes the sum. It validates the entire cohort before any admission callback or publication-row mutation, so a later row failure cannot leave a partially admitted overlay. It may then add counts to separate publication rows. It never changes a frozen source, timing report, median, source identity or producer LOC. The fresh Mech controls receive their own exact-source count overlay from the qualified canonical Mech audit, preserving their producer counts.
