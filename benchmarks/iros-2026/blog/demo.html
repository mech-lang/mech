Checking WebGPU availability…


  
Changing the backend or batch size resets both the filter and the simulation. CPU and GPU compile the same source; state migration between devices is not implemented in this example. Rendering shows the first filter in the batch.

  
The kernel checks the raw covariance update and stores its symmetric part. A constraint violation stops the episode without publishing the candidate; Reset starts from the source initial state. The Reactive section describes the long-run symmetry fault that led to this formulation.

  
Timing and drawing support
    
FPS includes animation scheduling and is capped by the display. Completed-turn time includes input binding, execution, validation, synchronization, and one filter's state readback; it excludes drawing and compilation. Throughput is batch size divided by median turn time. The summary uses the latest 60 accepted turns after five warmups, not independent benchmark trials.
