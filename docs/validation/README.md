# Historical validation archive

The 78 historical JSON receipts from Mech #910 are preserved byte-for-byte in
the [pre-#911 benchmark archive](https://github.com/mech-lang/benchmarks/tree/91f8a97a7f1af30b451a7864d68f767002505f0d/archive/compiler/mech-pre-911-bbd66acb9).
Its manifest records original Git blobs, SHA256 hashes and byte sizes; its
verifier compares the archive to Mech `bbd66acb9b3beacdc95356084df259ca172c8b98`.
Those receipts qualify their recorded historical revisions. Current regression
gates remain in Mech; the cleanup coverage ledger records transferred checks.
