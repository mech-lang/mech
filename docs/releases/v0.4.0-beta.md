# Mech v0.4 preview

This prerelease accompanies the IROS 2026 Rust for Robotics workshop. It is a
development snapshot for evaluation and feedback, not a stable release.

The [workshop article](https://mech-lang.org/iros-r4r-2026/index.html) develops a
bearing-only extended Kalman filter through numerical notation, Rust embedding,
reactive validation, and CPU/GPU execution. It includes a live WebAssembly and
WebGPU example, the complete Mech document source, Rust integration examples,
and archived benchmark evidence. The [poster is available as a PDF](https://mech-lang.org/iros-r4r-2026/poster.pdf).

This preview includes:

- Typed numerical graphs with interpreted, JIT, AOT, SIMD, and GPU execution
  paths, subject to each backend's supported operations and host capabilities.
- A Rust kernel interface for source embedded with `mech!`, JIT compilation,
  saved AOT libraries, repeated input updates, and checked state publication.
- A resident reactive runtime with explicit validation and rejection boundaries.
- Mechdown documents with a resident REPL, live outputs, and full-screen output.
- Typed atom modes and events in the workshop state-machine example, along with
  shared source-formatting improvements for imports, functions, and vectors.
- A corrected live EKF covariance update, prompted by its symmetry constraint,
  with retained CPU/WebGPU long-run, rejection, and rollback tests. The archived
  native benchmark sources and measurements are unchanged.

The standard distribution is the usual starting point. The full distribution
adds the broader scalar, machine, and robot-arm feature set. Download the build
for your target platform and check it against the supplied SHA-256 checksums.

The published numerical measurements describe the retained implementations and
toolchains, not a general performance guarantee. Browser timings are separate
from the archived native experiments. Runtime APIs and artifact compatibility
are still developing; nominal values supported by resident source compilation
are not all representable in the legacy bytecode-v1 export format.

Further work includes validation on additional robot hardware, host integrations,
standard-library coverage, and deployment feedback. Please report reproducible
problems through [GitHub issues](https://github.com/mech-lang/mech/issues), with
the build version, host platform, source, and steps to reproduce.
