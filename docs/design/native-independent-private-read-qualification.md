# Qualify scheduling independent private reads

`MECH_SCHEDULE_INDEPENDENT_PRIVATE_READS=1` enables the AArch64 rule under the existing packed-read and private fixed-view proofs. The synchronous caller admits the initialized flat view, checks the live owner of each writable array, and keeps the compiler's input and output packets separate from those allocations. The compiler reconstructs two disjoint address ranges in one view and checks that the later selector reaches the same dominating value on every incoming edge. It traces the intervening control flow and verifies that each store addresses a disjoint part of that view, a separately held fixed backing, or the compiler's output packet. Calls, unknown effects, cycles and alternate entries decline. The original later store uses the same computed address and all selected stores, source checks, return status and error origins keep their order.

Exactly one of 357 recorded bodies changes. It retains 9,960 code bytes and a 576-byte frame. All other code and addresses agree with the timed worker. The descriptor changes only in its source-form tag between the two enabled emissions. Disabling the rule reproduces the prefetch Object, descriptor and bytecode byte for byte.

## Validation

- The optimized build uses nightly 2026-03-03 and `-D warnings`, with `aot,canonical-native,canonical-native-program,canonical-native-program-runtime,canonical-native-runtime,jit`. The first build stopped on an unused import. The corrected library and producer pass. Decoded emission took 184.44 seconds and source emission took 240.13 seconds, including 55.91 seconds for the frontend.
- The focused JIT test executes 840 calls across disjoint and overlapping ranges, short proof extents, a differing incoming selector, an unknown store or view, alternate entry, and success→rejection→retry. The initial standalone attempts found the wrong nested module path, an obsolete builder signature, and a six-argument fixture that did not satisfy the production packet contract. The final three-argument fixture passes with warnings denied.
- Source and decoded workers pass 648 complete linked checks with pinned stream bytes, independent decompression, current capacity, alias preservation and cleanup. The separate parser oracle checks 136,192 positions with rejection origin 15525 and successful retry. All five architecture and catalog checks, formatting and Git whitespace pass.
- The separate managed Rust comparison reproduces all 13 bundle files and validates 88 outputs. It measures 0.701776× and 0.712639× Rust in its primary and confirmation cohorts. Full generated-application and hosted CI suites were outside this qualification.

The normally emitted worker takes 0.997551× and 0.998381× paired control in the two 81-case matrices. Both timing gates pass on every case. Random 1 MiB measures 1.055882× and 1.059833× Roc, with elapsed gains of 1.61% and 2.83% against the paired control. Eight literals slow 0.47% and 0.65% in those same runs while staying near 0.17× Roc. The first matrix's 74/81 result and the full repeat's 75/81 result are both retained.
