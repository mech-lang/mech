# Level-12 compilation on Apple M3

The pinned compressor takes **480.542 seconds** before this change and **172.567 seconds** after it under the same 5 ms sampling setup: **2.78× faster, 64.1% less elapsed time**. A separate final run without sampling takes **173.239 seconds**. All generated bytecode, native Object bytes and metadata remain exact.

## Boundary and environment

Apple M3 MacBook Air, 8 CPU cores (4 performance / 4 efficiency), 16 GB RAM, macOS 26.2. Rust 1.96.0 nightly `ec818fda3`, toolchain nightly-2026-03-03, with the repository's vendored Cranelift 0.131.3 and regalloc2 0.15.2. Base is [PR #973](https://github.com/mech-lang/mech/pull/973) at `4fff511238df193562e976dfa34fc3c354c60256`, IR355. Baseline capture started November 12; later trials continued November 13, America/New_York.

This is fresh source compilation through the exact compact diagnostic Object API used by the level-12 benchmark. It includes parsing, checked source compilation, canonical artifact creation/encoding, lowering, preparation, proofs and machine code generation. There is no previously cached artifact or native code. It excludes building the Rust compiler executable, linking a generated host executable and running compression. The ordinary managed API is a different boundary and was not timed here.

The 160,857-byte, 1,931-line source is the maintained compressor assembly with `deflate-compress-into(input<[u8]>, output<[u8]>)` as its entry. It reproduces the published source hash `331e659e92181d803b3d87218effe88f711c2e8ecad9f31838fc50991de1c5c9` and bytecode hash `a2a551911949f8c5fdc64273a43662c2a9c4953b853136c19d196692fdac45a7`. Lowering produces 41,039 blocks and 22,460 values.

The initial focused Rust tool build took **513.68 seconds** (8m 34s) from a fresh target directory, separately from source compilation. The focused manifest initially omitted the root workspace's existing backend patches and failed feature resolution. It now selects those same vendored backends and retains the other locked dependency versions.

## Change

The existing checked guard rules and worklist remain in [guards.rs](../../hosts/gpu/src/native_artifact/program/compact/guards.rs), using the pure state in [guard_state.rs](../../hosts/gpu/src/native_artifact/program/compact/guard_state.rs). Unchanged states share immutable storage. Actual updates use copy-on-write; closure is recomputed only after a fact or relation changes, including a changed intersection. Expression intersections walk sorted entries, and projection peers are indexed once per closure while preserving the original inference order. Boolean facts use two bits per checked Plan value ID, so consistent intersections are wordwise ANDs and conflicting truths become unknown.

The compiler still expires relations on redefinition, keeps copied truths for their original versions, preserves conservative joins and retains the same runtime checks. This adds no cross-compilation cache, source recognition, alternate execution path or runtime permission. It changes no compressor source, algorithm, scratch capacity, pricing or generated-code version.

- All **9 focused tests pass** with warnings denied. These include 64,000 seeded update/join steps against the original tree-map analysis, 4,096 packed-fact steps across word boundaries, contradictory paths, redefinition, projection relations and independent shared owners.
- Every completed optimization and the clean final compile reproduce the baseline's exact source, canonical bytecode, native Object and metadata. Object: 1,141,992 bytes, SHA-256 `2a5cf7742a71959b288b40a7f1e5dfc3ca1a2b7502dee4304329fce1508896ff`. Metadata: 2,004,444 bytes, SHA-256 `a63abffb005718010b043783b345c607fe7d0de4c47d89057526d58a8b41ab19`.
- 7 additional fresh source controls cover Bool/U64/I64/F64 scalars, tail recursion, guarded owner selection and Boolean relations, with exact before/after Object and metadata checks.
- Fresh source compilation also reproduces the measured canonical artifact exactly, and decoded re-encoding preserves all 4,138,627 bytes.
- This is focused compiler qualification plus emitted-image equivalence. The full repository suite and the 81-input compression runtime campaign were not rerun. No new runtime-compression speedup is claimed.

## Integration with later #973 work

The fix is integrated over `eb006ab94e2880fa67ed67821c4da9d1b30601a1`.
That branch already includes [shared proof states](native-ownership-proof-sharing.md).
The integrated state retains sharing, copy-on-write updates and cached closure,
then adds packed Boolean facts, sorted intersections and indexed projection peers.
All seven existing regression tests remain, including the sibling-path test
moved into the pure state module. The integrated focused target passes **10 tests**.
A second differential harness compares 64,000 updates and joins with the exact
shared-state implementation on that branch, in addition to the original-map oracle.

The earlier 2.78× result uses the pinned `4fff511238` baseline; it does not measure
an additional 2.78× improvement over the branch's intervening shared-state work.
The independent timing comparisons are not multiplied.

The integrated compiler's fresh source-to-Object receipt is **171.451 seconds**
(2m 51s), with the same source, bytecode, Object and metadata hashes as the
original baseline above. This is a single additional diagnostic compile. The
outer `/usr/bin/time -lp` wrapper exits 1 after printing real/user/system time
because macOS denies `sysctl kern.clockrate`; the compiler reaches its final
receipt and writes every image. The wrapper failure is preserved, and this run
is not counted as a successful whole-process counter capture. No runtime timing
campaign was repeated.

The [integration archive receipt](../../benchmarks/mech-deflate/native-profile/compile-time-apple-m3-20261113.integration.archive.json)
pins the [final images, exact upstream oracle, preserved tests and failure record](https://github.com/mech-lang/mech/releases/download/evidence-native-compression-experiments-6/level12-compile-apple-m3-20261113-integration.tar.gz).
