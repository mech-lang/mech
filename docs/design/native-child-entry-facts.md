A child query runs after its initializer transfers the current arguments. Every reachable partition must prove a predicate; an unknown return, stale/redefined word, unknown view or fresh activation supplies no inherited permission. Ordinary and captured-child gate generation consumes these queries but removes only individually proved predicates. The currently selected captured versions have no caller-query proof and keep their checks.
